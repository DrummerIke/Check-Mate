# BORK Chess — статический прототип

Рабочий прототип онлайн-шахмат в BORK-стиле.

## Что внутри

- `index.html` — страница приложения.
- `style.css` — премиальный тёмный интерфейс в логике quiet luxury.
- `app.js` — логика игры, выбор сложности, усиленный локальный AI-бот, история ходов, FEN/PGN, предыгровой выбор сценария, подсказки тренера над доской только на уровне новичка, оценка силы хода, премиальные BORK SVG-фигуры, классический стиль и тренировки стратегий.
- `README.md` — инструкция по запуску и публикации.

## Как запустить локально

Откройте `index.html` в браузере.

Если браузер блокирует модульный импорт с CDN при открытии файла напрямую, запустите локальный сервер:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

## Как развернуть на GitHub Pages

1. Создайте новый репозиторий, например `bork-chess`.
2. Загрузите в него файлы из этой папки: `index.html`, `style.css`, `app.js`, `README.md`.
3. Откройте репозиторий на GitHub.
4. Перейдите в `Settings` → `Pages`.
5. В разделе `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Сохраните.
7. Через некоторое время сайт будет доступен по адресу вида:

```text
https://ВАШ_ЛОГИН.github.io/bork-chess/
```

## Как вставить в Google Sites

В Google Sites:

1. Откройте нужную страницу.
2. Нажмите `Вставка`.
3. Выберите `Встроить`.
4. Перейдите на вкладку `Встроить код`.
5. Вставьте код:

```html
<iframe
  src="https://ВАШ_ЛОГИН.github.io/bork-chess/"
  style="width:100%; height:900px; border:0; border-radius:24px; overflow:hidden;"
  loading="lazy"
  allowfullscreen>
</iframe>
```

Для мобильной версии можно уменьшить высоту до `760px`, если блок слишком высокий.

## Важно

В этой версии AI-бот локальный: он использует оценку материала, позиционные таблицы, мобильность, шахи и minimax с глубиной до BORK Mode. Перед партией игрок выбирает сценарий — свободную игру, тренера или комбинации, а также цвет, силу соперника, стиль подсказок и стратегический фокус; после старта интерфейс переходит к доске. Обучающий слой можно включить вручную: он распознаёт популярные дебюты, включая сицилианскую защиту, на уровне новичка показывает короткий кандидат на ход прямо над доской, на остальных уровнях ведёт статистику качества ходов без подсказок и даёт библиотеку основных тактических мотивов. Для турнирной силы следующего уровня можно подключить Stockfish WebAssembly.
